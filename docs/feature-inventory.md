## 1. 사용자가 접근 가능한 모든 기능 목록

### 1-1. 온보딩 (Onboarding.tsx)

| 기능 | 유형 | 설명 |
|------|------|------|
| Enter 키 / 화면 클릭 | 버튼 | 부팅 시퀀스 시작 |
| 코어스파크 부팅 | 애니메이션 | 5단계 색상 전환 (Cyan→Green→Purple→Orange→White), ~18초 |

### 1-3. 채팅 인터페이스 (page.tsx)

| 기능 | 유형 | 설명 |
|------|------|------|
| 메시지 입력 | 텍스트 영역 | 오로라 글로우 보더, 자동 높이 조절 |
| 전송 | 버튼 / Enter | 메시지 전송, Shift+Enter로 줄바꿈 |

## 2. 프롬프트 입력 → 게임 생성 전체 플로우

```
┌─────────────────────────────────────────────────────────────┐
│ Phase 0: 온보딩                                             │
│   Enter 클릭 → 코어스파크 부팅 (~18초) → 이름 입력 → 입장   │
└─────────────────────────┬───────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────┐
│ Phase 1: 웰컴 화면                                          │
│   카테고리 탭 선택 → 카드 stagger 등장 → 카드 클릭           │
└─────────────────────────┬───────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────┐
│ Phase 2: 채팅 진입                                          │
│                                                             │
│ Step 1. AI가 타이핑 프롬프트 안내                             │
│   "OO님, 아래 명령어를 직접 입력해보세요!"                    │
│   > 우주 슈팅 게임 만들어줘 █                                │
│                                                             │
│ Step 2. 학생이 직접 타이핑 후 Enter                          │
│   프롬프트 점수 평가 (1-5성)                                 │
│                                                             │
│ Step 3. AI 빌드 시퀀스 (띵킹 도트 → 빌드 라인 애니메이션)    │
│   · 분석 중... → 코드 생성 → 최적화 → 완료                  │
│                                                             │
│ Step 4. AI 응답 스트리밍 (타이프라이터, 8-16ms/글자)         │
│   설명 텍스트 + 주요 기능 소개                               │
│                                                             │
│ Step 5. 아티팩트 패널 자동 오픈                               │
│   코드 탭: 줄 단위 순차 등장 (35-60ms) + 신택스 하이라이팅   │
│   800ms 후 자동으로 플레이 탭 전환                           │
│                                                             │
│ Step 6. 게임 실행                                            │
│   iframe 로드 → gameExtensions 자동 주입                    │
│   → 학생 플레이 시작                                        │
│                                                             │
│ Step 7. 후속 인터랙션                                        │
│   제안 힌트 표시 → 학생 직접 타이핑                          │
│   Vibe 커맨드 → postMessage → 실시간 게임 수정              │
│   비주얼 테마 → CSS 주입 + 날씨 Canvas 오버레이             │
│   게임 오버 → 점수 + 재시작/전환 제안                        │
└─────────────────────────────────────────────────────────────┘
```

### 상세 단계별 함수 호출 체인

```
1. 학생 입력 → InputArea.handleSend()
2. → page.tsx doSendMessage(text)
3.   → scorePrompt(text) → 프롬프트 점수 평가
4.   → addBuildSequence() → 빌드 애니메이션
5.   → findResponse(text) → SCENARIOS 매칭
6.   → ScenarioResponse { text, gameHtml, artifactCode, suggestions }
7.   → AIMessage 생성 (streaming: true)
8.   → streamResponse() → 글자별 스트리밍
9.   → onArtifactOpen() → ArtifactPanel 활성화
10.  → getGameHtml(gameId) → 게임 HTML 로드
11.  → iframe.srcdoc 설정 → 게임 실행
12.  → gameExtensions 주입 (터치, X-Ray, 날씨 핸들러)
13.  → timeline.record() → 세션 기록
```

## 4. 연령별 필터 작동 방식

**현재 구현 상태: 명시적 연령 필터 없음**

대신 다음과 같은 간접적 연령 대응:

| 방식 | 설명 |
|------|------|
| 카테고리 분류 | 게임(전연령), 수학(초등~중등), 과학(중등~), 시뮬레이션(전연령) |
| 프롬프트 점수 | 입력 복잡도에 따라 1-5성 → 간접적 수준 파악 |
| 교사 강제 선택 | 교사가 특정 게임으로 고정 가능 (instructor 패널) |
| 콘텐츠 난이도 | 구구단(초등), 테트리스(전연령), 도트RPG(중등) 등 자연스러운 분류 |
| Coming Soon 표시 | 미완성 항목은 비활성화 (클릭 불가) |

**향후 구현 권장사항:**
- `scenarios.ts`에 `ageRange: [min, max]` 필드 추가
- 온보딩에서 학년/연령 선택 → 카드 필터링
- 교사 패널에서 연령 범위 제한 설정

## 5. 다국어 지원 현황

| 항목 | 상태 | 상세 |
|------|------|------|
| UI 텍스트 | 한국어 Only | 모든 버튼, 레이블, 피드백 한국어 |
| Vibe 커맨드 | 한/영 | "속도 올려줘" + "speed up" 둘 다 인식 |
| 테마 키워드 | 한/영 | "비" + "rain", "눈" + "snow" |
| AI 응답 | 한국어 Only | 모든 시나리오 응답 한국어 |
| 폰트 | 한국어 최적화 | Noto Sans KR (본문), JetBrains Mono (코드) |
| 부팅 텍스트 | 영어 | 터미널 스타일 (> system boot...) |
| 교사 패널 | 한국어 | 설정 항목 한국어 |

**다국어 확장 시 필요 작업:**
- `scenarios.ts`에 `locale` 분기 추가
- `vibeCommands.ts` patterns에 언어별 배열 확장
- UI 라벨을 i18n 키로 교체 (react-intl 또는 next-intl)

| 비주얼 테마 CSS | 웹 디자인 기초 | 중등~고등 |

### 6-4. 창의적 체험활동

| 시나리오 | 활동 | 대상 |
|----------|------|------|
| 게임 리믹스 | 게임 디자인 프로젝트 | 동아리/방과후 |

## 7. 에러 발생 가능 상황과 대처법

### 7-1. 네트워크/서버 에러

| 상황 | 원인 | 대처법 |
|------|------|--------|
| 게임 공유 실패 | Vercel KV 미설정 (`KV_REST_API_URL` 누락) | `.env`에 KV 환경변수 설정, 또는 공유 기능 비활성화 |
| 리더보드 로드 실패 | 동일 (KV 미설정) | 로컬 모드로 전환 (localStorage fallback 없음) |
| 갤러리 빈 화면 | KV에 저장된 게임 없음 | 최초 1개 게임 공유 필요 |
| 빌드 실패 | edge runtime + static generation 충돌 | `export const dynamic = 'force-dynamic'` 추가 |

### 7-2. 게임 실행 에러

| 상황 | 원인 | 대처법 |
|------|------|--------|
| 게임 화면 안 나옴 | iframe sandbox 제한 | `allow-scripts allow-same-origin` 확인 |
| 게임 오버 중복 감지 | postMessage 이벤트 중복 발생 | `setTimeout` 디바운스 (500ms) 적용 완료 |
| Vibe 커맨드 안 먹힘 | iframe selector 미스매치 | `.artifact-panel-open iframe` 또는 `iframe` fallback |
| 비/눈 효과 안 보임 | CSS 오버레이가 Canvas 뒤에 숨김 | Canvas 기반 Weather Overlay 시스템 적용 완료 |
| 테마 CSS 적용 안 됨 | cross-origin iframe 접근 제한 | `contentDocument` 시도 → srcdoc 재작성 fallback |
| 테트리스 줄 안 사라짐 | `collapseLines()` 후 render 타이밍 | clearAnim 150ms + 즉시 render 적용 완료 |

### 7-3. UI/UX 에러

| 상황 | 원인 | 대처법 |
|------|------|--------|
| 입력창 텍스트 잔존 | 전송 후 textarea clear 누락 | `InputArea.clear()` 호출 추가 |
| 타이프라이터 미작동 | setState 과다 호출 | useRef DOM 직접 조작으로 전환 |
| 신택스 태그 텍스트 노출 | innerHTML 미사용 | `dangerouslySetInnerHTML` 적용 |
| 사이드바 모바일 겹침 | 반응형 미적용 | 900px 미만 자동 접힘 |
| 오디오 재생 안 됨 | 브라우저 autoplay 정책 | 첫 클릭에 `initAudio()` 호출 |

### 7-4. 교사 패널 에러

| 상황 | 원인 | 대처법 |
|------|------|--------|
| PIN 인증 실패 | 잘못된 PIN | 정확한 PIN: 0608 |
| 강제 설정 안 먹힘 | localStorage 접근 제한 | 시크릿/프라이빗 모드 해제 |
| 설정 초기화 안 됨 | 다른 탭에서 캐시 | 모든 탭 새로고침 |

### 7-5. 빌드/배포 에러

| 상황 | 원인 | 대처법 |
|------|------|--------|
| `Module not found` | 게임 파일 import 경로 오류 | `lib/games/` 경로 확인 |
| Vercel 빌드 경고 | edge runtime + static generation | 경고만, 실제 동작에 영향 없음 |
| 폰트 로드 지연 | 외부 Google Fonts CDN | `next/font` 로컬 폰트로 전환 권장 |
| 첫 로드 느림 | 12개 게임 HTML 번들 크기 | dynamic import + code splitting 권장 |
