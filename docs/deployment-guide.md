# 배포·운영 가이드 — 바이브코딩 아레나

> 대상: 교육기관 운영 담당자 / 외주 개발사. 2026-06 리뉴얼(Phase 0~3) 기준.

---

## 1. 배포 (Vercel 기준, 10분)

```bash
npm i -g vercel
vercel              # 프로젝트 연결
vercel --prod       # 프로덕션 배포
```

**API 키 없이 배포 즉시 동작합니다.** 게임 생성은 내장 시나리오 엔진이라 외부 API 호출이 없습니다.

### 환경변수 (Vercel Dashboard → Settings → Environment Variables)

| 변수 | 필수? | 설명 |
|------|-------|------|
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | 권장 | Vercel KV(Storage 탭에서 생성 → 자동 주입). 리더보드·공유 링크·갤러리의 **영속 저장**. 없으면 인메모리 폴백 — 동작은 하지만 서버 인스턴스가 바뀌면 초기화되고, 서버리스 환경에선 인스턴스 간 공유되지 않음 |
| `NEXT_PUBLIC_INSTRUCTOR_PIN` | 권장 | 교사 패널 PIN. **기관마다 다르게 설정하세요** (기본 `0608`). 변경 후 재배포 필요 |
| `NEXT_PUBLIC_BASE_URL` | 선택 | 공유 링크·OG 태그의 기준 도메인 (예: `https://arena.example.com`) |

> ⚠️ `NEXT_PUBLIC_*` 변수는 클라이언트에 노출됩니다. PIN은 학생 접근을 막는
> **소프트 락**이지 보안 경계가 아닙니다 — 성적·개인정보를 다루지 않는 현 구조에선 충분합니다.

## 2. 도메인·브랜딩 체크리스트

- [ ] 커스텀 도메인 연결 (Vercel → Domains)
- [ ] `NEXT_PUBLIC_BASE_URL`을 커스텀 도메인으로 설정
- [ ] `app/layout.tsx` metadata의 title/description을 기관명에 맞게 조정 (선택)
- [ ] `public/icons/` 아이콘을 기관 로고로 교체 (선택, 192/512 PNG + SVG)

## 3. 교실 네트워크 요구사항

| 항목 | 요구 |
|------|------|
| 대역폭 | 첫 로드 약 0.3MB/학생 (First Load 215KB + 폰트). 30명 동시 접속 기준 일반 학교 와이파이로 충분 |
| 외부 호출 | 폰트 CDN(jsdelivr, Google Fonts) 허용 필요. 그 외 외부 API 없음 |
| 브라우저 | Chrome/Edge/Safari 최신. 태블릿은 가로·세로 모두 지원 (900px 미만: 게임 위/채팅 아래 분할) |
| 오프라인 | 미지원 (서비스워커 의도적 미등록 — `public/sw.js`는 향후 오프라인 설계용 보류분) |

## 4. 수업 직전 운영 절차 (기기 N대)

1. 각 태블릿에서 사이트 접속 확인
2. (선택) 태블릿마다 `/instructor?pin=PIN` 접속 →
   - **학생 이름** 미리 입력 (출석부 순서대로)
   - **게임 강제 지정** (전원 동일 게임 수업 시)
   - **연출 생략** ON (2회차 이후)
3. 설정은 **기기별 localStorage**에 저장 — 기기마다 따로 설정해야 하며, 브라우저 데이터 삭제 시 초기화됩니다
4. 수업 종료 시: 학생 화면 우하단 `수업 기록 N건 ⤓` 탭 → JSON 수거 (선택)

## 5. 데이터·개인정보

- **수집하는 것**: 학생이 입력한 이름(별명 권장), 게임 점수(리더보드 등록 시), 대화 로그(기기 내)
- **저장 위치**: 이름은 sessionStorage(탭 닫으면 삭제), 리더보드/공유 게임은 KV(또는 인메모리), 대화 로그는 메모리(다운로드 전까지 미전송)
- **계정/로그인 없음** — 이메일·전화번호 등 식별 정보를 받지 않습니다
- 공유 게임은 30일 TTL로 자동 삭제(KV 사용 시)

## 7. 트러블슈팅

| 증상 | 원인 | 해결 |
|------|------|------|
| 공유/리더보드가 비어 있음 | KV 미연결 + 서버 재시작 | Vercel KV 연결 (Storage 탭 → 생성 → 변수 자동 주입 → 재배포) |
| 교사 설정이 적용 안 됨 | 다른 기기/브라우저에서 설정함 | 학생이 쓰는 그 기기·그 브라우저에서 `/instructor` 설정 |
| 학생 이름이 계속 유지됨 | 같은 탭 재사용 | 탭 닫고 새 탭 (sessionStorage 초기화) — 교사 프리셋 이름은 `/instructor`에서 해제 |
| 부팅이 안 넘어감 | (구버전) | Enter 또는 우하단 `건너뛰기` — 약 7초 후 자동 진행 |
| 폰트가 깨져 보임 | 방화벽이 CDN 차단 | jsdelivr·fonts.googleapis.com 허용 |
