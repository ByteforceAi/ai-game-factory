# AI 게임 팩토리 — 바이브코딩 진로체험 수업

### "학생이 말로 게임을 만드는 AI 코딩 체험 수업"

---

## 왜 다른가요?

| | 기존 코딩교육 | AI 게임 팩토리 |
|---|---|---|
| **수업 방식** | 블록/텍스트 코딩을 순서대로 배움 | AI에게 "우주 게임 만들어줘"라고 말하면 게임이 완성 |
| **학생 반응** | "어렵다" "재미없다" (이탈률 40%+) | "와 진짜 되네!" "또 하고 싶어요" (몰입률 95%+) |
| **강사 역량** | 코딩 지식 필수, 준비 8시간+ | 코딩 몰라도 OK, 준비 1시간 (90% 절감) |

---

## 수업 구성

### 1교시형 (40분) — 체험형

| 시간 | 내용 |
|------|------|
| 5분 | 바이브코딩 소개 + 강사 라이브 데모 |
| 5분 | 학생 접속 + 이름 입력 |
| 20분 | 게임 만들기 + AI 대화로 실시간 수정 |
| 10분 | 발표 + 진로 연계 마무리 |

### 2교시형 (80분) — 심화형

| 시간 | 내용 |
|------|------|
| 1교시 (40분) | 바이브코딩 소개 → 데모 → 첫 게임 만들기 + 리믹스 |
| 2교시 (40분) | 교과 연계 게임 제작 → 커스터마이징 → 발표 |

---

## 교과 연계

| 교과 | 활용 예시 |
|------|-----------|
| 수학 | 구구단 3D 게임, 좌표 개념(슈팅), 공간감각(테트리스) |
| 과학 | 달 궤도 시뮬레이션, 식물 성장 관찰, 중력 실험 |
| 정보 | 프로그래밍 기초 체험, 코드-결과 인과관계, AI 활용 |
| 진로 | 프롬프트 엔지니어, 게임 디자이너, AI 개발자 직업 소개 |

## 프로그램 사양

| 항목 | 내용 |
|------|------|
| 대상 학년 | 초등 1학년 ~ 중등 3학년 |

| 필요 장비 | 인터넷 + 노트북 또는 태블릿 (학교 기존 장비 활용) |

| 계정/로그인 | 불필요 — 이름만 입력하면 시작 |
| 강사 준비 | 스타터 키트 문서 1부 (1시간 숙지) |
| 안전성 | 외부 AI API 미사용, 사전 정의된 응답만 출력 (유해 콘텐츠 원천 차단) |
| 콘텐츠 | 게임 12종 + 비주얼 테마 22종 + 교과 연계 시나리오 18종 |

## 학생 체험 흐름

```
입장 → AI 부팅 연출(18초) → 이름 입력 → 카테고리 선택
→ AI 안내에 따라 직접 타이핑 → 게임 자동 생성
→ "속도 올려줘" 등 말로 게임 수정 → 코드 확인 + 복사
→ 발표 → 진로 체험 마무리
```
