## 1-3. 첫 게임 만들기 실습: 따라하기

> 아래 순서대로 직접 해보세요. 5분이면 됩니다.

**Step 1.** 사이트 접속 → Enter 키 누르기

**Step 2.** 부팅 애니메이션 감상 (약 7초 — 급하면 Enter 한 번 더 누르면 건너뜀)

**Step 3.** 이름 입력 → "수업 시작하기" 클릭

**Step 4.** "게임" 탭 클릭 → "네온 슈터" 카드 클릭

**Step 5.** AI가 안내하는 문장을 직접 입력창에 타이핑합니다
```
우주 슈팅 게임 만들어줘
```

**Step 6.** Enter를 누르면:
- AI가 생각하는 애니메이션이 나타남 (빌드 시퀀스)
- AI 응답이 한 글자씩 타이핑됨
- 오른쪽에 코드가 한 줄씩 나타남
- 자동으로 게임 화면으로 전환

**Step 7.** 게임 플레이! 키보드 방향키 + 스페이스바로 조작

**Step 8.** 게임이 끝나면 AI가 "다시 하기" 또는 "다른 게임"을 제안합니다

## 1-4. 리믹스 실습: 같은 게임을 5가지로 변신시키기

게임을 만든 후 입력창에 다음을 **직접 타이핑**해보세요:

| 순서 | 입력 | 결과 |
|------|------|------|
| 1 | `속도 올려줘` | 게임이 빨라짐 (즉시 반영!) |
| 2 | `무적 모드 해줘` | 죽지 않는 모드 |
| 3 | `네온 테마 적용해줘` | 화면이 네온 색상으로 변함 |
| 4 | `비 오게 해줘` | 게임 위에 비가 내림 |
| 5 | `사이버펑크 테마 적용해줘` | 사이버펑크 색감으로 변환 |

이 모든 변경은 **게임을 새로 만들지 않고** 실시간으로 적용됩니다!
학생들에게 "AI에게 말만 하면 바로 바뀐다"는 걸 보여주는 데모 포인트입니다.

## 2-5. 학생 질문 예상 FAQ 10개

**Q1. "이거 진짜 AI가 만든 거예요?"**
> 네, 진짜 AI가 만든 코드예요. 코드 탭을 누르면 실제 프로그래밍 코드를 볼 수 있어요. 이 코드를 복사해서 메모장에 붙여넣고, 파일 이름을 game.html로 저장하면 집에서도 열어볼 수 있어요.

**Q2. "다른 게임 만들고 싶어요!"**
> 입력창에 "다른 게임 보여줘"라고 타이핑하면 다시 게임 선택 화면으로 돌아가요. 또는 왼쪽 위 ✎ 버튼을 누르면 새로 시작할 수 있어요.

**Q3. "내가 원하는 게임을 만들 수 있어요?"**
> 지금은 준비된 12가지 게임 중에서 고를 수 있어요. 하지만 같은 게임이라도 "속도 올려줘", "색깔 바꿔줘" 같은 말로 완전히 다른 느낌으로 바꿀 수 있어요!

**Q4. "코드를 직접 고칠 수 있어요?"**
> 코드 탭에서 코드를 복사해서 집에서 수정해볼 수 있어요. 학교에서는 AI에게 말로 수정하는 방법을 써보세요.

**Q5. "왜 게임이 안 만들어져요?"**
> 인터넷 연결을 확인해보세요. 그래도 안 되면 페이지를 새로고침(F5)하고 다시 시도해보세요.

**Q6. "점수가 너무 낮아요 (별 1~2개)"**
> 별점은 여러분이 AI에게 얼마나 자세하게 설명했는지를 보여주는 거예요. "게임 만들어"보다 "우주 배경 슈팅 게임 만들어줘"처럼 자세하게 쓰면 별이 올라가요!

**Q7. "저장할 수 있어요?"**
> 코드 복사 버튼(📋)을 누르면 코드가 복사돼요. 메모장에 붙여넣고 game.html로 저장하면 집에서도 열어볼 수 있어요.

**Q8. "친구랑 같이 할 수 있어요?"**
> 각자 자기 컴퓨터에서 접속하면 돼요. 같은 게임을 골라서 누가 더 높은 점수를 받는지 겨뤄볼 수도 있어요.

**Q9. "이거 무료예요?"**
> 네, 완전 무료예요. 로그인도 필요 없고 이름만 넣으면 돼요.

**Q10. "집에서도 할 수 있어요?"**
> 네! 같은 주소로 접속하면 집에서도 할 수 있어요. 부모님한테 보여드려도 좋아요.

  - "오늘 한 것 = 프롬프트 엔지니어링. 실제로 이런 직업이 있어요."

# Part 5. 트러블슈팅

## 5-1. 게임이 안 만들어질 때

| 증상 | 원인 | 해결 |
|------|------|------|
| 화면이 멈춤 | 인터넷 끊김 | 와이파이 확인 → 페이지 새로고침(F5) |
| 빈 화면 | 로딩 실패 | 크롬 브라우저로 다시 접속 |
| 게임이 안 보임 | 아티팩트 패널 닫힘 | AI 응답의 파일명 버튼 클릭해서 열기 |
| 코드만 보이고 게임이 없음 | 플레이 탭 미전환 | 오른쪽 패널에서 "플레이" 탭 클릭 |

## 5-2. 인터넷이 느릴 때

- 부팅 애니메이션은 로컬에서 돌아가므로 느린 인터넷에 영향 없음
- 첫 페이지 로딩만 기다리면 이후는 빠름 (게임 코드가 이미 내장됨)
- 학생 30명이 동시 접속해도 문제없음 (각자 독립 실행)
- 정 안 되면: 강사 PC로 시연하고 학생은 순번제로 체험

## 5-3. 학생이 부적절한 프롬프트를 입력했을 때

- 이 플랫폼은 **외부 AI API를 사용하지 않습니다** (인터넷으로 질문을 보내지 않음)
- 모든 응답은 **미리 준비된 시나리오**에서 나옵니다
- 부적절한 입력을 해도 "무엇을 도와드릴까요?" 같은 기본 응답만 나옵니다
- 별도의 필터링이 필요 없습니다 — 구조적으로 안전합니다

### 팁 3: 수업 후 활동 아이디어
- 학생들이 만든 게임의 코드를 복사 → USB에 담아가기
- 가장 창의적인 리믹스를 한 학생에게 "바이브코딩 마스터" 칭호
- 학급 리더보드 대회: 같은 게임으로 최고 점수 겨루기

### 팁 4: 자주 하는 실수 피하기
- 설명을 너무 길게 하지 마세요 → 학생이 직접 해보는 시간을 최대한 확보
- 모든 학생이 같은 속도로 진행하길 기대하지 마세요 → 빠른 학생은 리믹스, 느린 학생은 기본 체험
- 코드를 설명하려 하지 마세요 → "코드가 이렇게 생겼구나" 정도면 충분
